# NVDA PC 微信增强功能对照

参考环境：本机安装的 WeChatEnhancement 2.4.4。实现采用独立 C# / UIA 代码，不复制插件 Python 源码，不依赖 NVDA。

| PC 微信增强功能 | 独立程序实现 | 状态 |
| --- | --- | --- |
| 全局搜索结果朗读 | 监听微信搜索结果窗口的 UIA 焦点变化，通过当前语音通道朗读名称 | 已实现，待用户实测 |
| `Ctrl+F` 聚焦全局搜索框 | 使用微信原生快捷键；PC 微信增强 2.4.4 已移除旧 `Alt+G` | 与当前插件一致 |
| `Alt+P` 聚焦公众号列表 | 微信前台动态注册并按 UIA 位置关系查找公众号列表 | 已实现 |
| `Alt+T` 聚焦通讯录列表 | 定位 `primary_table_.contact_list` 后设置焦点 | 已实现 |
| `Alt+V` 聚焦音视频悬浮窗 | 定位 `VOIPTrayWindow` 后设置焦点 | 已实现 |
| `F3` 切换通知 | 关闭 -> 仅提示音 -> 提示音加朗读 -> 关闭 | 已实现并验证 |
| 自动通知新消息 | UIA 事件与 500ms 轮询并存，RuntimeId 去重 | 已实现 |
| `Ctrl+Alt+上/下` 浏览消息 | 固定使用与插件相同的组合键，仅输入框聚焦时动态注册 | 已实现并验证 |
| `Ctrl+Alt+Home/End` 首条/末条 | 固定使用与插件相同的组合键，从当前聊天虚拟队列朗读 | 已实现并验证 |
| 虚拟消息队列 | 按聊天身份隔离，RuntimeId 合并，上限 500 条 | 已实现 |
| 队列上边界加载历史 | 临时释放 Ctrl/Alt、移动鼠标并滚轮向上加载，再恢复鼠标和修饰键状态 | 已按 2.4.4 行为实现，待用户实测 |
| 用户浏览时抑制自动通知 | 消息浏览操作后抑制 2 秒 | 已实现 |
| 微信输入框 NVDA TextInfo 修复 | 该功能替换 NVDA 内部对象和文本范围实现，独立 exe 无法改变其他读屏的对象模型 | 不适用于独立程序 |

## 热键作用域

`Alt+P/T/V` 和 `F3` 只在微信位于前台时注册。`Ctrl+F` 由微信自身处理。四个虚拟消息浏览热键固定为 `Ctrl+Alt+上/下/Home/End`，只在微信输入框具有焦点时注册，离开输入框立即释放，不占用其他程序快捷键；注册冲突时使用无 Hook 的按键状态轮询。

## 语音差异

原插件调用 NVDA 的 `ui.message`，必然走 NVDA 当前语音输出。本程序可选择争渡 `WeChatMsg` 独立通道、争渡读屏通道、保益 `WeChatMsg` 独立通道或 SAPI5。输入框 TextInfo 修复依赖 NVDA 内部对象替换，独立 exe 无法跨进程复刻；其余 2.4.4 对外功能均已实现。
