# 1.5.0 验证记录

> 测试日期：2026-10-29  
> 目标框架：.NET Framework 4.8 x64

## 原始音效

- [x] `SentMessage.mp3` 原始 SHA-256 与嵌入源一致。
- [x] `SIMToolkitSMS.mp3` 原始 SHA-256 与嵌入源一致。
- [x] 两个资源均原样嵌入 exe，不重新编码。
- [x] 打开会话自动朗读最后一条消息时同步播放对应方向音效。
- [x] 自己发送方向固定播放 `SentMessage.mp3`，对方发送方向固定播放 `SIMToolkitSMS.mp3`，程序集版本保持 `1.5.0.0`。
- [x] 输入框最近输入文本使用去空白规范化并保留短队列，优先识别自己发送的正文消息。

## 热键通知

- [x] 热键冲突只写入 LocalAppData 日志，不再弹出托盘通知，不再被 NVDA 读成“第 1 项，共 1 项”。
- [ ] 实机确认旧版助手退出后 `Ctrl+Alt+End` 可以正常注册；旧版进程仍运行时，系统本身会拒绝同一热键。

## 体积说明

- Release x64 exe：121,856 字节。
- 超过 100KB 的原因是按用户要求保留两个原始 MP3 音质；如果恢复 100KB 硬限制，需要接受音效重新编码或外置资源。

## Win10 LTSC 兼容修订

- [x] 版本保持 `1.5.0.0`，未升级到 1.6。
- [x] 设置窗口不再同步枚举 SAPI5 语音。
