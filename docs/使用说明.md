# 微信消息助手使用说明

## 启动

1. 在微信设置中开启“通用 > 读屏优化模式”。
2. 双击 `WeChatMsgHelper.exe`。
3. 程序不会显示主窗口，只在系统托盘区显示图标。
4. 配置和日志保存在 `%LOCALAPPDATA%\WeChatMsgHelper`，exe 同目录不会生成文件。旧版本留在 exe 同目录的 `config.ini` 和 `log.txt` 会在新版首次启动时自动迁移并删除。
5. 当前语音通道初始化成功后，程序会立即朗读“微信消息助手”以及当前版本号；通过托盘菜单退出时只提交“消息助手退出”，不等待完整播放或外部组件清理，随后直接结束隐藏进程。

## 设置

按 `Ctrl+Alt+S` 打开设置，也可以右键托盘图标后选择“设置”。

通知方式有四档：

- 关闭：不播放提示音，也不朗读。
- 仅提示音：新消息只播放系统提示音。
- 仅朗读：新消息只通过读屏通道朗读。
- 提示音 + 朗读：先播放提示音，再把正文加入朗读队列。此项为默认值。

“启动后自动监听微信”默认开启。“登录 Windows 后自动启动”默认关闭；勾选后会在当前用户启动文件夹创建快捷方式，不写注册表。

## 默认快捷键

- `Ctrl+F11`：朗读当前聊天的最新消息。
- `Alt+Shift+F8`：启动或停止自动监听。
- `Ctrl+Alt+P`：循环切换四档通知方式。
- `Ctrl+Alt+S`：打开设置。

微信位于前台时提供与 PC 微信增强 2.4.4 一致的快捷键：

- `F3`：在关闭、仅提示音、提示音加朗读之间循环。
- `Alt+P`：聚焦公众号列表。
- `Alt+T`：聚焦通讯录列表。
- `Alt+V`：聚焦音视频接听悬浮窗。
- `Ctrl+Alt+上/下`：在输入框焦点不移动的情况下读上一条/下一条消息。
- `Ctrl+Alt+Home/End`：读第一条/最后一条消息。

四个手动查看消息快捷键只在微信输入框聚焦时启用，离开输入框立即释放，不改变其他程序的快捷键行为；快捷键冲突时使用无 Hook 的兼容轮询。

全局搜索框使用微信原生快捷键 `Ctrl+F`。PC 微信增强 2.4.4 已移除旧的 `Alt+G`。

向前浏览到可见队列开头时，程序会临时释放 `Ctrl/Alt`、把鼠标移到消息列表并向上滚动加载更早历史，然后恢复鼠标位置和修饰键状态。虚拟队列按聊天分别保存，上限 500 条。

微信上下文快捷键被其他程序占用时不再弹出托盘通知。`Alt+P/T/V`、`F3` 和四个消息浏览热键会自动改用无 Hook 的按键状态轮询；全局设置热键冲突则只写入 `%LOCALAPPDATA%\WeChatMsgHelper\log.txt`。

## 语音通道

设置窗口可以选择六种语音模式，保存后立即生效：

- 自动选择：检测到 `BoyPcReader` 正在运行时优先使用保益独立通道；否则依次尝试争渡独立通道、保益通道和 SAPI5。任一通道初始化失败不会阻塞后续候选。
- 争渡独立通道 `WeChatMsg`：默认选择。新消息不占用争渡普通读屏通道，适合打字时继续完整朗读消息。
- 争渡读屏通道：使用争渡的普通读屏通道，行为会与当前读屏朗读共享。
- 保益第三方独立通道：动态加载保益安装目录中的 `byctrl-x64.dll`，调用 `BoyCtrlSpeak2`，设置 `useSlave=true` 和独立通道名 `WeChatMsg`；DLL 失败时用 Web API 的 `use_slave=true` 兜底。
- 保益读屏通道：同一官方 DLL 接口设置 `useSlave=false`，消息进入保益普通读屏通道；Web API 兜底使用 `use_slave=false`。
- SAPI5：不要求争渡运行，可选择系统已安装的语音，并调整语速与音量。

保益按第三方独立通道名称关联并保存该通道的语音库配置。可在设置中的“保益独立通道名称”字段修改并保存；程序重启后会继续把同一名称传给保益。留空时使用 `WeChatMsg`。

“忽略系统通知类消息”默认关闭。开启后会过滤撤回、进群、群公告、拍一拍等常见系统提示；手动朗读最新消息不受此过滤影响。

争渡通道直接加载争渡安装目录中的 `ZDSRAPI_x64.dll`。保益通道直接加载保益安装目录中的 `byctrl-x64.dll`，不会复制 DLL 到发布目录。两个读屏都只使用名为 `WeChatMsg` 的正式独立通道，不再创建 API、Web 或 M0Probe 等测试通道。

若日志显示“状态=3，朗读中=True”但没有声音，请检查所选争渡通道对应的语音库、音量和输出声卡。SAPI5 无声时请在设置中换一个已安装语音。

## 消息音效

当通知方式包含“提示音”时，程序按消息方向播放不同音效：

- 自己发送的消息：`SentMessage.mp3`。
- 对方发送的消息：`SIMToolkitSMS.mp3`。

1.7 起会主动缓存微信输入框正文，并优先使用消息气泡内部正文、头像和内容区域的位置判断收发方向，避免部分 Win10 系统把整行消息项坐标当成气泡坐标而混淆两个音效。

两个原始音效已经原样编译进 `WeChatMsgHelper.exe`，不重新编码、不降低音质，`dist` 目录不需要放 MP3。Windows 的内置 MCI 播放器只接受文件路径，因此程序第一次播放时会从 exe 资源解出到当前用户临时目录，退出时自动清理；不会写到桌面、exe 目录或发布目录。原始音效会使 exe 超过 100KB，这是音质要求与旧体积限制的直接冲突，本版优先保证音效原样。

## 托盘菜单

右键托盘图标可以启动或停止监听、选择通知方式、查看当前语音通道、测试语音通道、朗读最新消息、打开设置或退出。双击托盘图标等同于“朗读最新消息”。

## 常见问题

- 找不到消息：先打开一个具体聊天，并确认微信“读屏优化模式”已开启。
- 打开会话：程序会在 500ms 内识别新的消息列表并自动朗读最后一条；之后自己和别人新增的可见消息都会自动进入队列。微信会复用消息气泡元素，程序按“RuntimeId + 正文变化 + 会话”去重，不再只按 RuntimeId 去重。
- 监听恢复：如果微信重建了 UIA 消息列表或元素失效，程序会自动重新绑定事件并继续用轮询兜底，不需要关闭再打开会话。
- 没有语音：争渡通道需要争渡正在运行；保益通道需要保益悦听 11.8 或更高版本。也可以改选 SAPI5 验证消息监听和系统语音。
- 重复朗读：检测到 NVDA 时程序会提示，建议和微信读屏插件二选一。
- 配置位置：按 `Win+R`，输入 `%LOCALAPPDATA%\WeChatMsgHelper` 可查看 `config.ini` 和 `log.txt`。
- Win10 LTSC 设置超时：1.6 会在后台加载 SAPI5 语音，设置窗口不会等待语音组件；加载超过 3 秒时保留系统默认或当前已保存语音。
- UIA 操作超时：异常会记录到 `log.txt` 并自动降级，程序不会再显示 .NET Framework 的“继续/退出”异常窗口。
