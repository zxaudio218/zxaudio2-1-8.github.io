# M4 监听稳定性验证记录

> 测试版本：1.2.1.0  
> 日期：2026-10-28  

## 已完成

- [x] 会话发现周期由 5 秒缩短到 500ms。
- [x] 监听从全量停止/重绑改为按会话增量同步。
- [x] 会话身份使用“窗口句柄 + 消息列表 RuntimeId”，支持主窗口内切换会话。
- [x] 打开新会话后自动建立 RuntimeId 基线并朗读最后一条消息。
- [x] UIA Value/RangeValue、StructureChanged 和 500ms 轮询三路监听并存。
- [x] 新会话等待 750ms UIA 稳定后建立基线并朗读最终最后一条。
- [x] 自己和别人新增的可见消息使用同一消息气泡提取逻辑。
- [x] 某个会话 UIA 失效时只移除该会话，不再停止全部监听。
- [x] 1.5.0.0 提供自动、争渡独立、争渡读屏、保益待验证和 SAPI5 五种模式。
- [x] 配置使用 `SpeechChannel` 保存通道选择；争渡独立通道名称固定为 `WeChatMsg`。
- [x] 开机启动从 bin/obj 启动时也优先固定到 `dist\WeChatMsgHelper.exe`。
